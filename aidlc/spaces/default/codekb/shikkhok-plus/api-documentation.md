# API Documentation — ShikkhokPlus

Full rescan, 2026-11-13, commit `cb20fd1`. Source of truth: the committed `openapi.json` (OpenAPI 3.1.0, generated by `make openapi`, compared byte-for-byte with the live app by `tests/contract/test_schema_diff.py`). Parsed this run: **150 paths, 174 operations, 226 component schemas.**

## Conventions on every route

- **Versioning**: `/v1/` prefix; endpoints stay additive and clients ignore unknown fields [D-26]. Non-versioned: `/health`, `/account-deletion`, `/staging/last-otp` (staging only).
- **Auth**: `Authorization: Bearer <access token>` (HS256, 15 min, `iss`/`aud` checked; `app/auth/tokens.py`). Refresh tokens: 30 days, rotated, family capped at 90 days, reuse revokes the family.
- **Authorization**: every route resolves a lens dependency, except the asserted `PUBLIC_ROUTES` (14) and `LENS_EXEMPT_AUTHENTICATED` sets (`app/contract/routes.py`). Teacher routes may take `X-Workspace-Id` to pick a centre workspace.
- **Client headers**: platform and version headers recorded at sign-in and refresh (`app/accounts/clients.py`).
- **Errors**: one envelope `{code, retryable, message_key, details?}` (`app/schemas/errors.py`), mapped from five classes: `ValidationError` 400, `AuthorizationError` 401/403/404, `ConflictError` 409, `TransientError`, `FatalError` (`app/errors/`). Ceiling breaches are `ConflictError` (non-retryable).
- **Money**: always a JSON string through the shared `Money` component (`app/schemas/money.py`), enforced by the money-schema gate.
- **Phone numbers**: accepted in any common spelling, stored and returned as `+8801XXXXXXXXX` (`app/schemas/phone.py`). Email: trimmed and lowercased (`app/schemas/identifier.py`).

## Outbound interfaces

- **SMS**: `SmsGateway` protocol, one attempt, four outcomes, no retry; BulkSMSBD adapter; null adapter is the default; staging outbox records instead of sending (`app/gateway/`).
- **Email**: `EmailGateway`, SES over SMTP, HTML + text body (`app/gateway/email_html.py`), own global daily budget.
- **Push**: FCM, best-effort after commit, failure logged and not surfaced (`app/notifications/fcm.py`).
