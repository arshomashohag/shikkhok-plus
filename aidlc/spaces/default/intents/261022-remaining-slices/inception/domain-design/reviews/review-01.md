### Summary

The two decisions the brief doubted most — `Profile` as the address's home, and the backfill — are now sound and well-evidenced. The blocking problem is elsewhere: the design describes acceptance state being added but never states that the three existing lens grants must start reading it, and it claims the invitation lens rides a one-statement query whose built shape returns a single scalar enrollment id and cannot carry a set of pending seats.
