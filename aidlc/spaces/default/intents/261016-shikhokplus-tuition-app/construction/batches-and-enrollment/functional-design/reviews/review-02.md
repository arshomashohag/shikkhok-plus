### Summary

All seven iteration-1 findings are addressed and verified against the actual code and upstream artifacts; six are cleanly fixed and R-06 (the Batch CRUD deliverable-label mismatch) remains open as a Minor. Investigating the specific remedy applied for R-04 surfaced a new Critical issue the first review did not catch: BR6.2's corrected rationale is internally consistent but is built on a `deleted_at` column that does not exist anywhere in the upstream domain-design entity catalogue or Governance disposition manifest, which instead specify `relink_blocked_at` as the actual erasure-correctness mechanism — a mechanism the domain design calls out as necessary to prevent an erased student's returning number from silently reattaching to their own erased history. Because U4 is the Unit taking ownership of this table's shape, this needs to be corrected here rather than carried forward into U11. A related Major finding on column-naming divergence (`account_id`/`fee_override` vs. the catalogue's `student_account_id`/`fee_amount`, and the missing `guardian_phone`) compounds the same root cause: this Unit's entity model was built without fully reconciling it against the authoritative upstream catalogue it claims to extend.
